短笔记流，数据全部存在你自己的 GitHub 公开仓库里。

令牌只保存在本机浏览器里，不会上传到任何服务器。仓库是公开的，任何人都能读到你的笔记，注意别记私密信息。

1. 打开 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens

2. Repository access 选 Only select repositories，勾选你的笔记仓库

3. Permissions → Repository permissions → Contents 设为 Read and write

4. 生成后复制到上面的输入框。GitHub Pages 会自动从这个仓库部署这个 App。
