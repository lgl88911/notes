# 2026-11-08

## 项目：note_stream（随想 · 短笔记流 PWA）

用户需求：参考 qiaomu.ai/notes 的形式做手机 App 记短笔记，数据全托管 GitHub 公开仓库，支持文字/图片/音频/视频，本地保留全部、可按日期清理且翻页能回捞，支持搜索、删除时同步删远端。

技术选型（用户确认）：PWA 优先（后续可 Capacitor 打包 APK）+ 一条笔记一个 Markdown 文件 + 媒体放同仓库 media/。

实现要点：
- 纯静态、无构建步骤，ES module + IndexedDB；部署走 GitHub Pages（.github/workflows/pages.yml）
- 笔记 `notes/YYYY/MM/<id>.md`，id = `YYYYMMDDTHHMMSS-随机4位`（可字符串排序）；frontmatter 里 media 用单行 JSON 数组
- 媒体 `media/YYYY/MM/<id>/<k>.<ext>`，图片压 WebP 长边 1600，音频 MediaRecorder opus，视频限 25MB
- 同步：本地 pending 队列 → 串行 flush，媒体先传、笔记后写；删除走墓碑集合避免刷新树后复活
- 翻页：本地翻到底 → 按 remote tree 路径倒序拉更早的；清理前先按 id 前缀比较日期

验证方式（重要经验）：容器内系统 Chrome 无头运行直接 SIGTRAP 崩溃（133），agent-browser 也会依赖 Chromium，不可用。改用 Node + fake-indexeddb + jsdom 做两层测试：`test.mjs` 覆盖存储/同步/删除/翻页，`ui-smoke.mjs` 覆盖真实 DOM 交互。jsdom 里需 stub：IntersectionObserver、Audio、URL.createObjectURL、confirm、以及 **global.fetch（容器 undici 的 wasm 申请不到内存会 OOM）**。
